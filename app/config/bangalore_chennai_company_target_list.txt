========================
IMPORTANT FOR JOB AGENT
========================

Do not rank companies only by brand size.

For small and mid-size companies, increase relevance when:
- Experience requirement is 1–3 years or 2–4 years
- Python is a primary backend language
- FastAPI / Flask / Django is mentioned
- PostgreSQL / MySQL is mentioned
- REST / API / Microservices is mentioned
- Docker / Kubernetes / AWS / Azure is mentioned
- Celery / RabbitMQ / Kafka is mentioned
- React is mentioned for full-stack roles
- The role is based in Bangalore or Chennai
- The company is actively hiring multiple engineering roles

A small company with a strong technology match and 2-year experience requirement
should be allowed to outrank a famous company whose opening requires 5+ years.

========================
RECOMMENDED COMPANY-SIZE BUCKETS
========================

1–10       = Micro startup
11–50      = Small startup
51–200     = Mid-size startup / scale-up
201–500    = Growth company
501–2000   = Established product company
2000+      = Large company / enterprise

Do not exclude 1–50 employee companies.

For the user's 2-year backend profile, a 11–50 or 51–200 company can receive
a positive company-fit bonus when the job asks for 1–3 or 2–4 years and matches
Python + FastAPI/Flask/Django + PostgreSQL + APIs + microservices.

A 1–10 company should be treated as an opportunity-discovery category:
check carefully for legitimacy, active hiring, role clarity, compensation,
employment type, and technical relevance before recommending it.
